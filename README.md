Warung Rush: Dapur Kilat — a complete cooking game that runs offline in a desktop browser. You run a small Indonesian warung: orders arrive on the rail, you build each dish from the ingredients on the counter, fry chicken and eggs in the wok before they can be plated, and serve before the customer's patience runs out. Fast serves earn tips, streaks build combos, and the shift gets busier as the day goes on.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080. Click ingredients (or press 1–8), click a wok to lift a finished fry, click an order ticket to serve the plate. S serves the first matching ticket, X clears the plate, P pauses, M mutes.
